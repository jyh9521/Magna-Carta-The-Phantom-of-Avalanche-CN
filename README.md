# 真名法典：冰之魅影 简体中文汉化

初代 PC 版《Magna Carta: The Phantom of Avalanche》的简体中文汉化与现代 Windows 兼容性工程。

## 当前状态

项目处于样本分析阶段。已建立安装副本与哈希基线，606 个 FPB 文件原样往返一致。原版启动报告像素格式错误；中文显示、免 CD、无边框和现代手柄均未完成游戏验收，目前没有玩家可用的发布包。

首轮结果见 [样本与启动错误调查](docs/SAMPLE_AUDIT.md)。
