# 真名法典：冰之魅影 简体中文汉化

初代 PC 版《Magna Carta: The Phantom of Avalanche》的简体中文汉化与现代 Windows 兼容性工程。

## 当前状态

项目处于静态调查阶段。韩文原版安装样本尚未提供；中文显示、免 CD、无边框和现代手柄均未完成游戏实测，目前没有玩家可用的发布包。
