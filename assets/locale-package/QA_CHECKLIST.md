# 手工游戏内验收

本包是离线验证候选，不是已完成游戏内验收的正式发行。安装、校验及回滚命令不会启动游戏。只有明确需要试玩时，手动运行新副本`.locale-runtime/Start.ps1`；保留已有图形层，不自动切换驱动。此前使用FocusGuard且满足其版本条件时，可手工追加`-FocusGuard`。

- [ ] 标题、开篇两套誓言、菜单和教程：中文可读，无乱码、漏字或跨tile截断。
- [ ] 状态、物品、装备、技能、购买/出售、队伍配置：数字、属性、快捷键和选中/禁用状态正常。
- [ ] 字库：中文、原韩文、英文、数字、格式化参数和换行混排正常；字幕长度、描边、透明像素、滚动和缩放无异常。
- [ ] 开场词典和Game over：中文字幕不裁切，声音同步；SOFTMAX开头Logo整段原样保留；开发人员名单、职位、配音表、署名及版权原样保留。
- [ ] 新游戏剧情与各类分支：对白顺序、事件控制符及结束行为正常。
- [ ] 保存和读档仍正常；旧存档名字不作为翻译验收项，不转换或改写旧存档。
- [ ] 可正常退出；按已有图形候选记录检查切换窗口和恢复。离线版本/模型测试不等于真实游玩稳定性。
- [ ] 系统错误和通知：仅在自然出现时记录截图、操作和退出状态，不为触发错误损坏档案或存档。
- [ ] 回滚副本后恢复原文/字库；原安装和原存档没有变化。

结果逐项记录为通过、失败或未执行，并附版本、资源清单摘要、截图/日志及复现步骤。未执行项不计通过。
