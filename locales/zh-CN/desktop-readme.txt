《真名法典：冰之魅影》简体中文汉化 + 全面增强补丁
Magna Carta: The Phantom of Avalanche Simplified Chinese Localization & Enhancement Patch
v1.0 正式版

为初代 PC 版《真名法典：冰之魅影》制作的简体中文汉化与增强补丁。
将剧情、界面汉化与高清显示、60 帧呈现、地图和战斗辅助整合在同一个包中。
这是完整覆盖补丁，不是完整游戏；安装时需要原版游戏，不需要叠加旧测试包。

一、v1.0 包含什么
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【简体中文汉化】
剧情对白、人物与地点名称、物品、技能、教程、菜单、系统提示、界面图片及部分视频文字。
配套中文字库、高清字形显示、中文标题画面，并修正文字排版、旧字残影和图片拼接。
原有配音保留；开发人员名单、SOFTMAX Logo、部分装饰文字和旧存档名称保持原样。

【画面与运行增强】
支持 1080P、2K、4K 和自适应分辨率，16:9 宽屏、全屏、窗口化与无边框窗口化。
可选 30 / 60 帧；60 帧模式加入人物、怪物通用模型与镜头插值，保留原游戏逻辑速度。
整合免光盘启动、现代 Windows 兼容组件，以及小地图和全屏半透明区域地图。

【操作与体验改进】
随机遇敌开关、普通连招辅助、暴走连招辅助。
整合对白显示、剧情字幕、战斗伤害数字、菜单宽度、场景载入等修正，
并纳入碰撞处理与连招声音后端的改进。
提供独立图形配置工具、启动入口、文件检查与原版资源恢复功能。

二、安装与启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 退出游戏和配置工具，备份原版游戏及个人存档。
   恢复原版时需要独立、匹配版本的原版备份，请勿将补丁覆盖到这份备份中。

2. 将本 ZIP 的全部内容解压到游戏根目录，即 MagnaCarta.exe 所在的文件夹。
   选择覆盖同名文件，保留 modules、fonts、maps、redist 等目录结构。
   不要只复制两个 EXE，也不要多套一层文件夹。

3. 双击 Configure.exe，点击“检查入口”。通过后选择显示设置并保存。
   默认设置：1080P / 无边框窗口化 / 60 帧。

4. 点击“启动游戏”，或双击 Game.exe 开始游戏。
   安装和检查本身不会自动启动游戏。

运行环境：Windows 10/11，.NET Framework 4.x / WPF。
玩家无需安装 Python，也无需运行 PowerShell 脚本。
安装在 Program Files 等受保护目录时，解压或保存设置可能出现管理员授权提示；
允许后继续原操作，取消后退出。普通可写目录不需要额外提权。

三、快捷键与设置
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

F5   切换随机遇敌；不影响剧情战斗、强制战斗或已经开始的战斗。
F9   小地图 → 全屏半透明地图 → 关闭。
F10  普通连招辅助。
F11  暴走模式连招辅助。

随机遇敌每次启动默认开启。v1.0 使用键盘和鼠标操作，未包含手柄和自由视角功能。
地图是区域线稿参考，不是自动导航；多层区域可能叠合，少数区域不显示地图。
如果 60 帧模式出现动作或显示异常，可在配置工具中切换 30 帧对照。

个人设置保存在游戏根目录的 enhancements.json。
更新补丁不会覆盖该文件；首次运行会在需要时导入旧版设置，存档位置保持不变。
“恢复默认”只恢复增强设置，不清除存档。

四、更新、排错与恢复
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

从旧版更新：备份存档，退出游戏，将本包完整覆盖到原安装目录即可。
旧版脚本和 config 目录不再由新入口执行，无需为了更新而手动删除它们。
请始终使用本包的 Configure.exe 和 Game.exe，不再使用旧版启动快捷方式。

检查失败：先确认解压位置正确且所有文件均已覆盖，再查看报错的具体文件名。
本包已包含所需固定运行组件，不需要再叠加历史修复包或随意替换 DLL。
仍有问题时，请附上报错截图、游戏场景、显示设置和对应日志反馈。

日志目录：
%LOCALAPPDATA%\MagnaCarta\Installations\<安装标识>\cache

以下命令供排错或恢复时使用，在游戏目录打开终端后执行：

  检查补丁文件：       .\Game.exe --check-installed
  检查启动条件：       .\Game.exe --verify-only
  检查配置工具：       .\Configure.exe --self-test
  检查原版备份：       .\Game.exe --check-baseline "D:\原版备份目录"
  恢复原版资源：       .\Game.exe --rollback "D:\原版备份目录"

将示例路径换成实际备份位置。恢复操作保留存档、个人设置、显示 INI 和检查工具；
恢复完成后，使用原版游戏入口，不再使用增强启动入口。
碰撞或连招声音问题需要对照时，可用 .\Game.exe --without-test-candidates 启动。

完整功能说明、更新和反馈入口见项目原始发布页及 GitHub Release。
