# 固定动画帧号的原生过渡插值（2026-10-14）

## Verified

旧骨骼缓存的sameFrameChange仅比较原生动画帧号和局部矩阵，不检查引擎逻辑tick。
原生MCAlpha RVA3b0c0在采样后通过object+f4的过渡计数、object+f0的历史局部姿态
改变局部矩阵；该路径不是仅由动画帧号决定。源证据及支持SHA256见MOTION_ACTION_CONTINUITY.md，
REA证据ev_ba778b5a7bfbfc3380d19d326da11eccb3b30907ac6e32a5eb45c4e2c7c67c54。

新增自有原生钩子回放保持frame=2，让相邻33ms逻辑更新中的过渡局部结果依次变为10、15、17.5。
旧生产代码在第二次更新立即显示15，未保留上一姿态的显示阶段，回归失败：
`FAIL new logic tick held animation frame must retain previous transition pose instead of snap`。

修复后，完整动作路径的“同帧变化”检查只在同一个引擎逻辑tick内进行。
相邻有效tick即使动画帧号相同，仍按既有c.previous/c.current更新并使用引擎余数插值。
逻辑世代/追帧/资源/模型/层级保护不变；旧非完整动作路径保留原sameFrameChange行为。
不改原生计时、过渡系数、原生姿态数组或游戏资源。

259项骨骼钩子回归覆盖首过渡、连续两个固定帧更新、中间显示姿态、重复绘制无累积、
绘制后原生绝对矩阵精确恢复。同一个逻辑tick内额外改变局部输入仍重置；
旧时钟路径的同帧变动也仍重置。此前完整层级桥接等248项仍包含在内。
独立源回滚重新编译恢复248项基准通过。
