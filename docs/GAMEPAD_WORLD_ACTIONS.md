# 探索交互与鼠标移动分离

## Verified：原生路径

源MCAlpha.dll SHA256 `5c701de93af6267b959c49e6927bee525bc0f3c68c8c6f51413515d13809d427`。
原 `0x5206e6d8` 接收世界场景this、事件发送GUI和事件编号；发送者ID须为0x42，
世界GUI+190须为1（探索）。事件0x11仅在场景+15b8已有邻近交互提示时置+15bc请求。
交互距离、NPC动作、脚本和对话仍由原更新处理，未强制执行剧情。
Space的原基类GUI方法 `0x52056162` 转发0x11，但全局键盘注入也会被其他GUI消费。
鼠标路径 `0x5206e8da/6e8fa` 使用光标及逆相机矩阵，解释X映射左键会触发光标方向行走。
原探索GUI `0x52080932`将0x11等原事件继续转发给场景。

## 修复范围

探索A不再注入全局Space，而是按下沿产生一次性交互请求。
原世界tick完成后，补丁再次检查探索可控条件与GUI ID，调用同一原场景处理器，事件0x11。
处理器自身的邻近条件保留；空地按A不强制对话，持续按A不重复请求。
请求在该tick末发出，原NPC/脚本处理在后续原tick执行；未增加逻辑更新次数。
原键盘Space不拦截。菜单A保持鼠标确认，开场A保持Esc跳过。
探索X不再注入左键，暂不绑定其他动作；菜单X仍保留原鼠标确认。
Start/B和地图保留本轮之前映射；不能据此宣称所有游戏状态已验收。

新增处理器入口字节守卫 `55 8b ec 83 ec 08 89 4d fc`；
共享运行入口仍校验源版本SHA。未知处理器在安装前拒绝，未盲写未知版本。

## 玩家验收

使用 `runtime/Play-gamepad.cmd`，复用`runtime/data`。
1. 靠近NPC，等原互动提示出现，松开摇杆后按A：应进入对话，不打开系统菜单。
2. 在空地按A、长按A：不得移动人物、打开菜单或反复触发。
3. 空地按X：不得再朝鼠标方向行走。X探索功能当前未绑定。
4. Start打开菜单，用方向/A/B操作；鼠标、键盘应仍可接管。
5. 主菜单与开场验证上一阶段修复没有回退。

本轮没有启动游戏；实体手柄、不同区域/战斗/对话状态仍待玩家验收。
标题亮度/悬停、完整60FPS视觉、视角移动、地图实用性仍未最终验收。
