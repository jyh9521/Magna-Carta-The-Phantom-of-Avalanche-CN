# 全文汉化执行管线

执行目标：全量文本提取 → 名词提取 → 术语表定稿 → 全文翻译 → 写入独立游戏副本。完整流程完成后统一实际测试，不再安排阶段性游戏测试；工具与调查不启动游戏、设置程序或商业 DLL。

## 文本覆盖清单

`tools/extract_text_catalog.py` 清点整个输入树，为每份文件记录路径、大小、SHA-256 和覆盖状态。原始安装只读，输出必须为新的独立目录。前后完整清单一致才保存结果。

```powershell
python tools/extract_text_catalog.py --source ORIGINAL_WORKSPACE --output build/fulltext-catalog
python -m unittest discover -s tests -p "test_*.py"
```

输出包括 catalog.json、quarantine.json、coverage.json、report.json。完整原文、资产和报告保留在忽略的 build/ 中，不提交商业资源。

## 未结构化文本与图像

启发式扫描发现 376 条原生字节范围候选，包括 CHA、UIS、JMU 和 DLL/EXE 内嵌文字。全部隔离，不据匹配字符串直接打补丁。扫描不是完整反编译文本提取，不能证明无匹配处没有文本。

独立结构调查另外识别 CHA 145 个名称候选、UIS 3 项、JMU 6 项，合计 154 字段。CHA 包含马车、轮子、粒子、重复对象名；这些字段不全部属于角色显示名。MCAlpha `0x520b216c` 静态加载器已确认角色 ID 和 100 字节名读取，但消费者及存档覆盖须继续追踪。

后续消费者调查确认：`0x520b3854` 按对象 `+4` 数值角色 ID 查询；`0x5207db56` 将对象 `+8` 名称传入格式化提示并进入文字问答框。名称确实存在显示路径，但不据此把所有对象名视为人名。`0x520b2c5f` 读档再次读取名称并覆盖对象 `+8`；`0x520b315f` 保存角色 `[0,3,2,1,4,6,5,20]` 的名称。仅修改 CHA 不保证既有存档显示中文，需要保持原存档内容的进程内显示适配。

证据分别为 `ev_8cea0cec4b9efd19271a1fab2da349880b6f5579132a87aa79c0285c69c8146b`、`ev_bbaea035df9f3544577e9df2ff5efb0e0d8ef8cc9a0e297ce6011d1ddb6cf922` 和 `ev_b14f1b03c2dbdf88030bc605759595298f79908425591d257bd822c2de87986a`。`0x520b3903` 实际加载 AmdData 模型数据，不是角色 ID 查询；保持该区别，禁止错误重命名模型路径。

图片调查已解码 BGR 422 图和 TXRS 3,149 图，合计 3,571 图。BGR 404 TGA、18 BMP；全部 422 图按真实像素重编码后逐字节一致。422 BGR 已审阅，310 个资源含可见文字/数字/残片，112 个未见可辨文字；TXRS 已完成3,149图首轮逐图筛查，24个候选进入复核。逐图筛查完成不代表所有细小文字、书页和装饰已经可靠转录。

Status、Carta、Item、Save/Load、Audio、Party 与标题按钮中的固定文字主要位于 BGR 图片。动态字库替换不覆盖这些标签。图片目录记录原资源 ID、哈希、文字、位置、置信度与未读清区域；粗包围框不是可直接抹除的文字蒙版。

334个图片文字/字形候选已补齐来源追溯。开篇六行誓言由韩文图片直接抄录，18个源tile通过组引用保留；24个资源仍缺可靠完整文字，此前28个裁切或部分文字资源中，25个已通过源像素拼接形成完整分组记录；3个残片仍保留复核。资源 ID 和原图不合并，文字分组不代表图像回写完成。运行字库、UI数字精灵、特效字形图集和书页装饰分别记录，不能合并索引。

游戏附带的保护组件及第三方运行库不纳入保护规避或任意整文件修改；原生候选先判定是否实际用户可见、是否属于本游戏。资源路径、查找键和内部标签保留，角色显示名不得与内部标识混改。

## 名词与翻译

目前已对 3,992 个结构字段完成首轮上下文名词审查，收集 110 项人物、地点、组织和机制候选，保留全部命中 ID 与前后文。候选译名不是已确认跨作品实体同一性；根术语表须经语义复核再定稿。

已将110项纳入 `locales/zh-CN/terms.json` 并生成根术语表，其中101项确定本作用词、9项用词待定；全部跨作品关系保留待复核，不从词面一致确认同人/同机制。固定参考完整词面匹配9项、确认共享概念0项。525个结构名称另完成首轮审查：ABI205、CHA145、ITM88、SGI87；319项建议译名、206项留空，仍需逐项语义及用途决定，不把建议直接写入内部动作/对象字段。

名词表包含原名、完整名称/简称/绰号、英文参考、目标名称、概念依据与源位置。人物身份、真伪形象、记忆人格、多人共享称号分开记录；同源短名不自动全局替换。技能、物品、武器名与新增角色资源继续补齐。

翻译以韩文为基准，按定稿术语和上下文逐条进行，保持全部保护标记；译文数据与通用工具分离。普通词不因系列统一而失去本作语义；已确认共享概念继承固定参考表的既定译名。

## 编码、字体与回写

原版“中文”可以通过 CP949 与 Chi 字库显示，不代表“测试”“汉”“龙”等简体字也能编码。完整译文先收集字符，再完成可复现字体覆盖、原生槽映射、测量/换行与资源容量校验，不能直接把全文转为 GBK 或 UTF-8。

写入对象为新的独立游戏副本；原安装、已验收基线、诊断副本及存档不覆盖。构建工具锁定原始哈希/预期字节，校验所有非目标字段和资源 ID 保留；原版重建、译文重建、回滚及干净检出重建分别记录。

## 源绑定译文与首批剧情资源构建

`locales/zh-CN/text/` 保存稳定字段 ID、原文字节 SHA-256、目标文本和翻译状态，不包含完整原文转储。首批190条剧情译文覆盖9个完整FPB：0075、0078、0084、0089、0090、0091、0092、0094、0095；该批构建时其余3,947个结构字段尚未提交目标文本。图片、硬编码和视频不包含在该字段计数内。

`tools/translation_data.py` 拒绝未知/重复ID、源字节漂移、缺译、空译、NUL、控制符次序或参数变化、已确定本作用词冲突及缺字。`$dNN`和`$cNN`作为完整控制标记保留，不拆开数字参数。保留内部字段须提供明确依据及空目标，不以批量“保留原文”替代翻译。

`tools/build_text_resources.py` 当前只处理已验证FPB。逐资源核对覆盖清单哈希、记录数、tag、ordinal和原文原样重建，再编码译文并更新目录偏移/长度。动态目标反解码逐条一致；字库仅修改映射声明的字形槽，原头部、度量和其他槽保持一致。输出为独立候选目录，不部署、不启动游戏。

默认要求整个所给catalog完整；`--allow-partial`仅用于明确的研究候选，仍要求选中每个FPB的全部字段齐备。catalog完整也不等于图像/硬编码/视频全部完成，因此构建报告持续保留`all_game_text_complete=false`，最终发布须另外完成整体覆盖门禁。

本批190条译文生成670字形、两套14/22像素原生字库。9份FPB、两份字库及构建清单重复构建逐字节一致；190条动态译文逆解码一致；源FPB/字库哈希不变。全量默认门禁拒绝缺译且未产生目录。自动测试194项基线与211项修改后均通过，独立FPB副本回滚恢复原字节；尚无本批剧情游戏内验收，不改写已验证游戏副本或存档。


后续新增78条地下水道事件与人物对话译文，第二批构建合计268条、18份完整FPB，其余3,869结构字段缺译。全部268条逆解码一致，769字形两套原生字库与18份资源重复构建一致。211项基线与217项修改后单元测试通过；完整门禁继续拒绝缺译，候选保持未部署。

`tools/collect_translation_corpus.py` 从多个源绑定译文文件按稳定ID生成字库输入，先验证源哈希、术语与控制标记，保留字段带明确依据且排除出目标字形集合；重复ID、输入漂移或缺译默认拒绝。268条收集结果与直接合并输入生成的两套字库逐字节一致。收集不推定语义或游戏内验收，不以临时手工合并文件作为重建前提。

视频实际范围现已清点：15个BMC与MOV.pak内3个成员，共18段、22,212帧离线解码；每秒及末帧989个样本、38接触页完成首轮审阅。4段确认烧录文字，包括开场词典、品牌、Game over及长片尾署名。16个来源哈希不变、36次工具调用退出0，未播放窗口或启动游戏。片尾完整转录、小号词典及短于抽样间隔的字卡仍有缺口，不能据未见字幕关闭视频全文范围。
