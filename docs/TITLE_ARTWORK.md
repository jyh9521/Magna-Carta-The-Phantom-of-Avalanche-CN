# 主界面艺术标题与菜单对比度

标题按明确布局改为“真名法典／银色横线／冰之魅影”。原前景英文标志和追加的普通中文说明不再叠用；开头SOFTMAX品牌视频保持原样。

新字标为单独透明RGBA图`locales/zh-CN/art/title-wordmark.png`，银白金属斜切面、衬线、深色阴影及分隔线与原前景标题风格呼应。两种背景尺寸分别使用源RGBA摘要锁定的LPD1背景修复增量；不提交完整原游戏背景。增量仅改变原前景英文所在矩形，背景装饰暗字、范围外原画和版权字卡保留。

原小号标题的最后“A”有8个亮像素位于BGR/0359的左缘，不能只改0357/0358两tile，否则残留最后一个字母。小号组合补全为0357/0358/0359，全部源tile及坐标明确；中文中心位于原画有效640像素范围内，不将768组合画布中未显示部分当作屏幕中心。大号仍使用0363/0364/0365。

通用组图构建器新增摘要锁定的背景增量与透明字标叠加。构建后逐像素证明增量/叠加框之外与原源RGBA相同，tile包装、头、尾、分配长度及尺寸保留；拒绝资产摘要漂移、无透明背景及越界增量。清理、背景和文字层分离，其他语言可替换对应资产/布局，不在通用工具硬编码中文文字。

主界面8份按钮资产0400–0407同步提亮：亮态暖白，暗态银灰；加深描边提高复杂背景上的可读性。资源ID、状态配对和点击布局不改，不将不同视觉状态合并为同一颜色。旧存档及人员名单保持既定范围。

新增1份标题tile后，图像总数203；完整离线包635资源。静态组合预览不是新的实际游戏截图，不证明最终运行时位置、按键/禁用行为或所有渲染状态。

构建入口仍为`tools/build_image_text.py`及`tools/build_image_groups.py`。透明字标、布局、背景增量、源摘要和字号/颜色数据均保存在locale目录，干净检出加指定原版和字体输入可重建，无需私有生成目录。设计源描述记录在`locales/zh-CN/art/title-design.json`。

生成素材经裁边和固定缩放参与可复现构建；运行构建不调用任何生成服务。仅分发原创字标与受版本锁定的背景增量，不将原游戏画面置于源码仓库。本轮未启动游戏。
