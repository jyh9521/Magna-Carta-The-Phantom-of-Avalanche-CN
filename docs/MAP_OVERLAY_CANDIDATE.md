# 区域大地图与小地图候选

本文描述初始地形候选。后续实时NPC／箱体、轨迹、玩家跟随小图与验收入口见`MAP_LANDMARKS.md`；初始边界说明不代表当前已加入的对象层仍缺失。

## Verified

REA已沿世界加载链确认：探索场景scene+10d0的资源ID传入8a3f0，再传430d0和2a673，最终2a723按Map/%04d.wrd读取；scene+1558为区域对象，区域+f0为brush，brush+124为地图资源对象，首字段为实际地图ID。观察器同时核对场景与资源对象的ID，拒绝旧场景/别名不一致，不猜测当前区域。

受控解码确认位置setter5a773将三参数复制到actor+154，getter5ab10从相同12字节读取；探索玩家指针scene+1564及actor+20所属场景由此前原生输入证据绑定。观察器在原世界tick完成后只读XYZ，不写坐标、碰撞、任务或存档；菜单/标题的源键盘轮询以空观察通知清除旧快照。快照时间超过250ms也隐藏图层。

169个1.400000资源均完成EOF解析和第一帧实例投影，共18409组均为单网格/单变换。按ASR已验证的列主序矩阵变换生成独立2048像素地形图。MCM1为40字节：magic4、宽高各u32、XY包围框4个float、视口origin2个float、scale1个float。PNG和metadata各自SHA锁定，原WRD不回写，派生资产不提交仓库。

图层使用独立NOACTIVATE/TOOLWINDOW/LAYERED/TRANSPARENT窗口，明确返回HTTRANSPARENT和MA_NOACTIVATE，不改游戏前台、不移动系统鼠标。菜单、失焦、非主窗口或无效快照隐藏图层；F8显示区域大图，F9显示左上角小图；XInput原生模式的View/Back和R3分别对应这两个开关，初始均关闭，不替换原罗盘。观察器安装时不等待GUI线程；有效世界tick才异步启动窗口，避免LoadLibrary/loader-lock中的GDI初始化与等待。WINDOW_READY与OBSERVER_READY分别记录，不伪报窗口创建成功。

XInput关闭时采用源版本键盘透传：保留原键盘和鼠标，不加载/轮询控制器，仅在候选开启时占用源轮询中的F8/F9。XInput开启时复用同一键盘桥；OFF恢复F8/F9原轮询状态。独立Windows消息消费者是否另绑定这些键仍需实测。

验证：原生数学/字段守卫13项；含隐藏窗口创建/停止、鼠标穿透消息和同一绘制路径PNG输出19项；世界输入23项包含无手柄时原移动/IAT不变及观察回调移除。控制器IAT样本验证透传不轮询XInput、F8/F9占用、其他键保留及精确回滚。受控窗口不是商业游戏画面验收。

## 未验证与边界

这是当前区域的第一帧几何参考图，不是跨区域世界地图，不包含任务点、NPC标记、路径规划或已探索遮罩；所有楼层投影叠加，动画平台变化不更新。7个1.300000版本明确不显示，记录ASSET_UNAVAILABLE。XY投影与人物轨迹的实际对齐、全屏合成和所有剧情/战斗切换仍待玩家验收。

图层独立33ms刷新，玩家点显示逻辑坐标，不宣称该点复用骨骼60Hz插值。大图不是暂停菜单，游戏继续运行，鼠标点击穿透。Alt+Tab原鼠标问题仍搁置，图层隐藏不作为该问题修复。正常已验收显示、正文和字体保持不变。

## 手动入口与验收

生成：先运行tools/build_map_atlas.py从用户原WRD生成本地图，再运行tools/prepare_map_trial.py包装独立模块及locale地图标题。

Play-maps.cmd开启候选环境，进探索场景后F8/F9开关（Xbox原生模式为View/Back、R3）；Play-without-maps.cmd关闭，同画质同手柄设置对照。纹理生命周期和自由视角在该入口关闭，避免未验收功能叠加。

验收：F9后沿直路、转角行走，检查点与地形相符；F8检查图尺寸与文字，重新按键关闭；切换区域、读档、系统菜单、返回标题，确认不显示旧图；地图打开时确认原点击和空格正常。必要时保留session/profile.log、截图、区域资源ID和位置；实际日志依次包含OBSERVER_READY、OBSERVER_VALID和WINDOW_READY，只有资产实际加载才出现ASSET_LOADED。

窗口图像由UI线程显式释放，进程退出的DLL全局析构不调用GDI+，避免退出期间已终止绘制线程留下的锁等待。图层文字、间距与小图尺寸按1080/2160客户端高度缩放，地图资产2K，不复用原游戏256像素纹理选择器。
