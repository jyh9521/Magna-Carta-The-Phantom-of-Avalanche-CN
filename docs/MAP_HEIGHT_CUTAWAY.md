# 可选高度剖切地形候选（2026-10-15）

## 已观察问题

未剖切的0031离线图由大块上层面覆盖内部轮廓；0009原始静态对象中NPC/箱体Z约0.5，地面平面约0，上层平面常见70/100。这些是本地资源读数与离线图像观察，不等于当前玩家所在楼层或所有区域的通行面定义。

## 实现

`build_map_atlas.py --clip-z-max HEIGHT` 可选地把渲染多边形裁到 `Z <= HEIGHT`。跨平面的三角形按边求交，保留下方三角形/四边形，不粗暴丢掉整面；重复边界顶点去重。剖切多边形按平均高度排序；未设置参数的旧排序和渲染路径保持原样。

完整场景XY包围框、origin/scale与MCM1元数据不随裁切重算，因此切面不会偷偷改变玩家点的坐标域。只有PNG渲染多边形变化。清单明确记录 `render_filter.clip_z_max` 与 `geometry_only=true`；非有限高度在输出创建前拒绝，全场景被裁空时拒绝生成空白候选。

```powershell
python tools/build_map_atlas.py --source runtime/data/MAP --output build/map-cutaway-candidate --size 2048 --ids 9 31 --clip-z-max 30
```

新生成的0009/0031均为2048像素。0031剖切预览可见内部墙线和柱体，未剖切图的上层遮挡被移除。两图的MCM1与原图字节相同；不带参数重建的PNG也与原工具基准字节相同。独立源码回滚后重建再次复现相同基准PNG和元数据。

八项回归验证屋顶排除、地面保留、交叉面求交、边界去重、非法高度、视口不漂移、默认图一致和全裁空拒绝；实际资源另做图像/摘要对照。
