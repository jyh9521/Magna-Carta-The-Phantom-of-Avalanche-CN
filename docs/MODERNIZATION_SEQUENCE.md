# 现代化推进顺序

2026-10-13 玩家确认：宽屏、4K、高清标题画面正常。该确认属于当前组合的画面验收，不扩展为完整剧情、战斗或全部硬件验收。

按最新决定依次推进：

1. 完整60FPS动作：补齐骨骼、世界位移/转向、摄像机的共享渲染插值，保持33ms逻辑与事件；实际游玩验收与受控验证分别记录。
2. 现代Xbox/XInput手柄：恢复开发，替换已失败的坦克式方向键适配，逐项确认探索、菜单、战斗输入消费者。
3. 增强配置工具：集中管理已实现的显示、帧率、输入选项，持久化、预检、启动与恢复默认值。
4. 引擎Bug修复：按可复现现象和版本绑定证据推进，不凭旧作Bug数量宣称修复。
5. 新功能：评估大地图、小地图、自由视角的资源、摄像机和输入基础，逐项建立可关闭候选，不提前承诺未知地图数据覆盖率。

Alt+Tab鼠标失效单独搁置，不进入当前修复阶段。汉化正文和字体资源保持冻结。每个候选保留正常副本，提供玩家手动入口、具体验收项及关闭/回滚路径；不自动启动游戏。
