# 环绕视角下的键盘／手柄方向

## Verified：当前模块缺陷与修复

原环绕视角仅替换提交给驱动的矩阵，不修改游戏相机+80。
手柄移动却读取原相机+80，因此显示方向和移动方向不一致。
键盘相机入口原先没有输入适配器，仍沿用坦克方向键。
新世界夹具发布一个不同于引擎相机的显示视角，旧代码实际失败：
`orbit movement follows displayed view instead of unmodified engine view`。

新增线程局部InputView：真实相机提交后复制最后显示的环绕视角。
输入读取要求相机身份相同、数据有限且年龄不超过250ms；计时器回绕受检查。
时钟失效/换代、驱动撤销、F7重置或环绕关闭清除覆盖。
没有写游戏相机，NPC、脚本、碰撞和原移动调用次数不变。

环绕打开时，左摇杆及物理方向键依显示视角决定世界XY方向。
物理方向键映射为原生前进调用加已核的方向设置，不叠加坦克转向。
非方向按键和菜单保持原路径；环绕关闭后键盘恢复原坦克操作。
单独相机入口使用不轮询XInput的键盘适配，未接手柄也有效。
手柄相机组合入口另行启用已有XInput模块。

## 验证范围

世界输入夹具43项；相机真实驱动钩子夹具80项；InputView纯状态11项。
覆盖显示视角与引擎视角不同、物理键盘优先、无XInput、菜单排除、关闭恢复、
相机发布值与实际驱动提交一致、身份/年龄/时间回绕等。
独立源码回滚恢复此前35/77项行为，当前候选不回滚。
夹具和VerifyOnly不证明实机移动体验。没有启动游戏。

## 玩家验收

键盘入口：`runtime/Play-camera.cmd`。
手柄组合入口：`runtime/Play-camera-gamepad.cmd`。
两者共享`runtime/data`，没有复制游戏。配置默认设置未改。

1. F6打开环绕，Ctrl+Alt+小键盘4/6左右旋转视角。
2. 方向键或左摇杆向屏幕右：人物应向屏幕右移动；再检查上、左、下。
3. 改变视角后重复上述操作，方向不应仍绑定旧镜头。
4. F7重置；键盘恢复原操作，手柄恢复原相机方向。
5. 打开菜单检查导航不受移动适配影响；检查对话和区域切换。
