# 剧情语音字幕、首次F5提示与CG转场历史

## 已验证：资源与译文

全量扫描597份Field：565份按受支持原生前缀和事件尾精确解析至EOF；32份为旧版、截断或不匹配格式，
保留拒绝原因和摘要，并额外逐DWORD检查603/604标记，未发现额外独立音频调用。
不把这32份标为完整格式解析成功，也不修改其内容。
原生603路径为 `7ae06 → 49720 → 49864 → 5a69 → AIL_start_3D_sample`。
67处调用引用48个SED，其中21个有语义语音，形成51条字幕；其他27个为音效、非词语发声或静音。
普通700/704另生成2374条有语音对白绑定，只有原框隐藏或被全屏遮幕覆盖时启用字幕后备。
701/705构造的框语音参数为-1；702/703为选择框，不当成独立语音。

数据位于 `locales/zh-CN/story-captions.json`，通用编译与审计工具为 `tools/build_story_captions.py`。
每个资源包含音频SHA256、总时长、韩文核对文本、译文、分段毫秒和状态。
既有译文按FPB来源复用；新增结尾旁白沿用人物、家族和组织术语。
结尾473至479全部覆盖，视频对应476（克罗伊斯自治权）；不只处理开场。

安静语音另作增益归一化、关闭VAD的复核，找出普通VAD漏掉的193、470、471，
再与同场FPB原有句子相互核对。噪声中识别出的“字幕设置”“感谢观看”等高无语音概率文本不采纳。
ASR为核对材料，不把越过原音频时长的生成文本或不存在的旁白加入字幕。
生成器拒绝缺词、空译文、重复资源、越界/重叠时间以及原音频摘要变化；不重编码或改写原音频。
原黑幕、原语音、原剧情事件与游戏资源保持不变。

## 已验证：音频与生命周期

SED使用实际Miles 3D start/stop/end/release入口记录播放时钟，不累计渲染帧，也不把游戏暂停标志
误当成语音暂停。真实stop冻结计时；真实start从0开始并换代；end/release立即清除。
停止时提供者返回8或2都结合实际stop记录判定，单纯自然播放结束则清除字幕。
若原语音继续播放，字幕继续跟随；不额外改变原版的音频暂停行为。
每帧同时核对当前Field帧号、场景、事件槽、完整参数指纹、声音对象、通道句柄与播放状态。
跳过标志、事件释放、音频结束、通道复用、场景销毁或切至其他类型场景，都不沿用旧字幕。
普通对白后备读取实际SVD流身份与Miles毫秒位置，原框可见时不重复绘制。
原有 `$n` 仅在字幕显示副本中转为换行；FPB控制码和原数据不变。
原Miles流暂停也会返回状态2，和结束相同。普通对白另观察实际 `AIL_pause_stream` 入口，
冻结并恢复剩余超时，避免长暂停期间被当作结束。只匹配仍有效的原对白/资源/通道/流身份。

自有夹具覆盖暂停后长时间等待、重新开始、跳过、切场、空白间隙、句柄复用、销毁和原框/遮幕后备。
另以受支持原Miles和原SVD静音回放验证：暂停时流毫秒游标冻结，字幕流身份保留；即使墙钟期限已过，原生自动结束仍等待实际暂停语音，结束后清除；
只映射受控原生方法，不执行游戏入口。音频/FPB/引擎摘要回读不变。

## 已验证：最终画面顺序与F5

原F5使用外部Layered窗口，首次入场依赖包装层窗口合成注册。
新路径在引擎 `c20c` 原生present之前，向受支持驱动的既有后缓冲提交DIB像素；
不创建外部提示窗口，不向窗口DC绘字，不要求Alt+Tab，也不增加额外present。
焦点判断取原驱动实际呈现的HWND及其根窗口，支持渲染子窗口，避开引擎另一路输入/HUD窗口的初始赋值依赖。
原驱动BackOut（3155）会先对活动D3D场景调用EndScene；新路径保留这一顺序，
在同一次EndScene之后、同一次呈现之前提交字幕和F5像素，避免在活动场景中跳过绘制。
没有面板时仍走原生EndScene/present。丢失表面不循环重试，焦点丢失不绘制。

字形仅绘入自有内存DIB；后缓冲DC只接收StretchDIBits，并配对释放。
保存/恢复FPU/SIMD状态和LastError。冷启动首帧、活动D3D场景、原黑幕之上、
焦点切换、表面丢失、原生present次数及全映像字节回滚均由离线夹具验证。
这不是显卡/全屏画面的游戏内验收。

## 已验证：CG转场插帧历史隔离

旧插帧以模型、动作、骨骼缓冲和逻辑时钟为身份。新场景或CG能复用这些对象，
旧世界坐标/根骨骼高度仍会作为插值起点，出现跨场重放旧位置的窗口。
新增真实Field draw/销毁边界，在场景、Field编号或场景模式改变时丢弃旧渲染历史，
保留原逻辑时钟与60帧呈现。另核对原生镜头命令500/501：单帧切镜与立即模式切换清理历史，
持续镜头运动和同一命令后续更新不每帧清理。

同一模型、动作、骨骼分配和逻辑tick的夹具，在缺少边界时重放旧位置/高度，退出1；
加入边界后，躯干与部件XYZ高度采用新场景值、保持帧稳定、原矩阵精确恢复，退出0。
此前剧情位移与碰撞保护的所有权隔离一并保留。未降低帧率，未按地图坐标特判，未强制贴地。
该证据确认上述跨场历史缺陷；没有现场存档，不宣称所有悬空表现只有这一种根因。

```powershell
python tools/build_story_captions.py --catalog locales/zh-CN/story-captions.json --source runtime/data --output build/native/story_caption_data.h --report build/story-overlay-evidence/full-audit.json

```

CMake可用 `STORY_CAPTION_CATALOG` 指定其他locale目录的数据，用 `STORY_CAPTION_SOURCE_ROOT`
指定用户提供的原资源目录。字体族由locale数据提供。不得把自有Miles桩DLL放进游戏目录或测试包。
统一模块更新仍使用既有摘要守卫事务，回滚还原原12模块及清单，保留游戏数据、存档和设置。
测试者手动启动最新完整包，依次验收首次F5、开场及结尾旁白、暂停/跳过/切场、60帧CG转场和出门动作。
游戏未自动启动。显卡合成、视觉布局及实际场景最终验收由测试者完成。

本轮完整测试包显式使用构建器 `--frame-rate 60`，不从本地设置导出个人配置，
也不改通用构建器原有30帧默认值。维护目录现有60帧设置及其他设置在模块事务中保持原样。
