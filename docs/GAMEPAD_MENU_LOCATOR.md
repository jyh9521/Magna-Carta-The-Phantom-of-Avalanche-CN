# 菜单可见定位指针（2026-10-14）

> 2026-10-15 证据范围更正：下文“绘制槽/调用原绘制”实际只验证了原生位置与矩阵准备槽，未验证指针像素。原游戏还具有独立的显示状态；原始指令回放与后续验收边界见 [原生光标链路](GAMEPAD_NATIVE_CURSOR_PATH.md)。当前问题仍待真实画面确认。

玩家最新反馈：看不出自己的光标移动到了哪里。前一候选在手柄接管后跳过整个原生光标绘制，而多数菜单没有可靠且明显的独立选中反馈；隐藏坐标不等于完善手柄焦点提示。

## 政策修正
菜单中恢复原生定位指针，探索中仍按手柄/鼠标所有权隐藏和恢复。
这不是新做的焦点框，也不是叠加系统鼠标；使用当前f2388对象的原生绘制，位置就是f20b0/f20a8所对应的A确认命中点，不再另算屏幕坐标。
不改变方向单一归属、死区、连选节奏、A/B/Start和X空格，不重新开放双区域方向派发。

## Verified
cursorMenu在键盘轮询时记录!worldScope，modernGamepadCursorHidden返回cursorHidden && !cursorMenu。
记录输入时的模式而非在绘制时读取thread_local worldScope：后者在世界tick的finally阶段恢复，不能用来判断后续绘制是探索还是菜单。
卸载重置缓存；日志cursor_hidden与实际绘制条件一致。原游戏自身隐藏光标的条件不被强制解除。
