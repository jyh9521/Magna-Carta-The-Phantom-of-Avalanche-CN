# 小地图呈现、视距与性能修复

2026-10-25，仅更新共享测试运行目录；不更新安装器或正式发行 ZIP，不启动游戏。

## 对应反馈

1. **大图左上角闪烁小图**：删除地图独立 HWND、WM_PAINT、窗口 DC、定时器及置顶/定位循环，复用既有 `frame_overlay`。地图占槽位 2；唯一原生帧按 map → caption → notice 顺序合成，沿用 EndScene 后、native present 前的插入点。
2. **小图视距近**：玩家居中裁剪从 240 改为 720 世界单位，线性视距三倍；小地图仍受实际 atlas 范围限制。
3. **掉帧**：三个可复用 DIB 缓冲保存地形、动态标记和预乘 alpha。完整地形只在换图/尺寸/模式/裁剪改变时重绘；大图人物移动不重绘地形。小图显式裁剪源图，避免把整个 atlas 放大后再丢弃画面外像素。输入逐原生帧处理，地图像素最多每 33ms 更新一次。不再每帧创建位图/字体或调用 SetWindowPos。
4. **指南针下方**：在原生 backbuffer 坐标中定位，跟随同一游戏 UI 缩放而非桌面/客户区物理像素；顶部为 108 UI 单位，右边距 6，宽度 152。再按帧尺寸约束面板边界，原生显示缩放和黑边不会让地图脱离指南针。
5. **游戏风格**：小图使用铜金细框、折角、深褐底和浅铜线稿；大图只画半透明线稿/标记。删除调试网格、巨大标题、图例和坐标。绿 NPC 点、橙色方向箭头、紫色容器、奖励金圈、青色出口菱形的语义保持不变，小面板标记按可用空间缩小。

## 已验证的源码与资源依据

支持的引擎 SHA-256：`7e8649425217d3b99d52d11c679761a88c57b125c241b331aea5c25e00e3b15e`。

- 原指南针创建路径 `MCAlpha+0x70810` / 内部 `+0x7083a` 使用 FDI 0136，方向图层使用 FDI 0137。右侧水平定位由已有 wide_ui 修正为 `virtualWidth - 100`。
- FDI 加载器 `+0xb5c64`、框架构造 `+0x4d5fd/+0x4d7b9` 和原资源交叉核对：`FrameData/0136.fdi` 有效绘制节点类型 3、资源号 234，指向 `BGR/0234.BGR`，不是同编号 BGR 0136。
- FDI 0136 SHA-256：`175056f4553947d5b2b6725d9f93d24b7271676220ea79adba16a01d40b54254`。
- BGR 0234 画布为 128×128，非零 alpha 外接矩形为 `[0,0,97,97)`。图像 SHA-256：`a17914d8c60bc0014830c6d8d1920974f8bb6004a4f1040b8883e13f694159aa`。
- FDI 0136 的声明宽高为零，不能把这些字段当作可见指南针尺寸；108 留出 11 个 UI 单位间距。
- `MCAlpha+0xf1b4c` 是现有 UI 高度基准；地图只读，不更改游戏分辨率、坐标或资源。缺失/异常高度使用 480。部署新模块时额外核验 FDI/BGR 摘要并纳入运行清单 data，后续 VerifyOnly 继续检查。


**高置信原因，非重新实机复现：** 旧 WM_PAINT 明确向窗口 DC BitBlt；项目已记录 DDrawCompat 对这一路径的虚拟屏幕重定向问题，和用户提供的左上角小图残影一致。离线基线复现的是重复窗口绘制路径和性能开销，不声称复现完整游戏闪烁。修复通过彻底移除该路径，而非调整窗口置顶或刷新时间。

生产绘制探针覆盖：小图/大图/关闭唯一面板、失效快照清空输出、尺寸变化强制重建、大图动态标记不重建地形、所有位图创建调用计数，以及 8 种帧尺寸 × 3 种 UI 高度（24 组）下指南针留白和屏幕边界。合成探针使用实际预乘 alpha 和保留表面，确认透明像素保留场景、字幕在地图上方、每帧一次 DC/原生 present、失焦/丢表面处理及字节精确撤回。

本机离屏 1280×720、移动 60 帧的基线绘制约 **28.625ms/帧**，存在 1 次窗口 DC 拷贝和 60 次重复位图创建；修复版本同口径约 **0.306ms/帧**，窗口 DC 拷贝与重复位图创建均为 0。新增的实际 provider + alpha blend 探针约 **1.980ms/帧**。两种修复指标口径不同，不相加、不当作真实游戏帧率；耗时随机器负载变化，不做脆弱的计时断言。

`runtime/maintenance/minimap-polish-20261025/` 保留原始源码/模块摘要、基线探针、构建/测试日志、最小部署撤回记录、保护文件摘要、DIFF_FILE.patch、VERIFICATION.txt 和可执行 ROLLBACK.sh。只对变化文件建立撤回副本，不复制游戏资源。
