# 光标隐藏改接实际绘制槽

## Verified（2026-10-15）

旧手柄隐藏钩子接在 `be374+18 → 38c24`，该钩子属于位置/矩阵准备，跳过该钩子不会直接阻止绘制，反而可能保留旧位置缓存。这一接错边界由原始指令和生产槽位共同证实，不等于已经复现玩家全部现场症状。

原生遍历 `38bd7` 调用虚表 `+c → 48774`。该函数先执行基类前置处理，检查 `38a2f`（对象 `+118/+114`），允许时执行绘制状态准备、`400d1` 精灵提交及收尾。REA：ev_610b79898e5de4b86d2b52e2b282e9aab62b088c63c06457554f3b4ee1f42e88、ev_e9a27674992c56cb69ad9b0ad8f06281f7a11a41456c77755bb4236768aaa5ea、ev_c1b5c447d5ba4e83d21db99f2c2467c329dc073d7fd88276e77f88bd52046ff1。

修正仅将当前原生光标的隐藏条件移到 `be380` 绘制槽；`be38c` 保持原始指针。探索由手柄拥有时跳过当前光标绘制，但位置准备仍执行；真实鼠标接管与菜单时原样执行绘制。共享类的其他精灵不受隐藏条件影响。原生显示状态、过场隐藏、图形状态和其他子节点不被强制更改。

安装/卸载检查原始位置准备槽、绘制函数前导字节、21 个输入与准入槽，未知状态在写入前拒绝。独立夹具旧生产源加新断言实际 RED：`FAIL cursor preparation must remain original while render suppression uses its own slot`。修正后验证隐藏时位置准备仍调用、绘制被跳过、鼠标接管恢复绘制、菜单仍绘制、无关精灵保留、卸载精确恢复。原始指令回放新增两项：隐藏状态的 `48774` 直接返回，可见状态到 `48445` 图形准备入口即停止，未执行外部图形接口。

## 手动验收

入口仍为 `runtime/Play-gamepad.cmd`，组合入口为 `runtime/Play-motion-gamepad.cmd`：

1. 主菜单及状态菜单使用方向导航，检查指针可见，A 按下再松开确认项一致。
2. 探索中使用手柄应隐藏原生指针；持续移动后动一下鼠标，应在当前位置恢复，而不是闪回旧位置。
3. 返回菜单检查指针恢复；右侧菜单与绿色箭头仍应只有一个区域响应方向。
