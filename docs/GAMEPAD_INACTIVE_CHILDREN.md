# 手柄导航：非活动GUI子节点不能隐藏父按钮

## Verified：原生分发顺序与资格字段

支持MCAlpha.dll SHA256：
`5c701de93af6267b959c49e6927bee525bc0f3c68c8c6f51413515d13809d427`。
REA离线读取55134：先逐个调用子GUI的输入分发，只有子GUI返回1才停止；
否则继续检查自身vtable+1d0并处理原生按键。
基础GUI的该槽指向565d2，该函数通过567ed读取对象+160、通过4d3a0读取+e8；
两个活动条件都满足后才进一步检查独占/阻断状态。

特别注意：基础GUI没有listener不等于不会消耗输入。
55134可能在自身资格通过后返回1，而事件函数566cb只是有listener时才转发。
因此，不能仅凭listener为空就忽略一个仍可接收输入的子GUI。

## 旧候选的可复现缺陷

方向焦点收集器只要看见一个已知GUI子节点，就排除父按钮，
即使该子节点的+160为0或+e8为0，根本不参与原生输入。
最终回归用合法的基础GUI、原生矩形链表及非活动装饰子节点，经实际
安装后的分发槽进入导航逻辑；旧生产代码在独立构建中失败：
`FAIL decorative GUI child cannot hide actionable parent button`。

## 修正与边界

递归收集返回子树中是否存在满足原有活动过滤条件的GUI。
只有这类子节点才保留原来的父节点排除；隐藏或禁用子节点不再使父按钮漏选。
活动子GUI即使没有listener或可收集矩形，也继续保留原分发优先级，
不因“没有焦点目标”就把父按钮加入列表。独占模态、原生方向消费者、
矩形范围/数量、源前缀/槽守卫及原分发调用保持不变。

20项原生UI夹具通过，包含禁用子节点、隐藏子节点、活动但无listener的子节点、
有真实目标的子节点与此前模态/原生方向/精确卸载检查。
独立源回滚恢复16项旧行为。437项Python检查通过。
