# 物品菜单与字幕基线修正

2026-10-13后续游戏截图确认灰度字幕可读，同时指出EA徽标缺角、翻页位置、侧边标题方向、音效竖线及中文基线问题。该反馈不作为修正后的游戏验收。

## 已验证的离线原因与修改

- 0261银钥匙清理框右界209覆盖了EA左缘；新排版/清理右界205，EA区域与原图逐像素一致。
- 0284/0285及0423/0424原图128×128是填充纹理，实际原标签alpha外框为91×21，原英文字母位于约x7..83，中心约45。旧中文按整张纹理居中在64，导致实际按钮偏右和裁字。新文本区x5..88、y1..18，以46.5居中；完整91×21旧字/影子清理，保留全部容器元数据。源像素对照已验证，新的运行时呈现仍待观察。
- 0262原英文侧标题采用旋转，中文应逐字正立竖排。通用构建器新增`flow=vertical`、`glyph_gap`，保留原英文旋转能力，但拒绝竖排和旋转同时启用；目标为物、品、状、态从上到下。
- 0191旧SOUND左列在x23/24，先前清理从25开始留下细线。条内清理左界改20，保护原圆角/滑条，x20..24、y91..107验证为完整黑底。
- 先前灰度生成器为每字选择最大字号并按墨迹高度居中，因此字符字号和排版基线均漂移。同输入XY受控模型基线字号13/14、基线13/12复现该模式；统一字体/基线后为13/13、13/13。现按每套完整1,898字符选择一个字号和`ls`基线，不按每字墨迹重新缩放/居中。

真实锁定Noto Sans SC 500布局为：14像素格统一12字号、baseline11；22像素格统一19字号、baseline17。完整字符集合共同容纳、不裁任何字形且源末行留空，原生14/22推进、映射、行距、抗锯齿与四向描边保持不变。符号的相对高度按字体自身设计，不再把句号移动到格子中央。ASCII/韩文字库仍走原路径，不改商业模块。

## 可复现验证

`tests/test_ui_alignment.py`对源绑定计划检查EA保护、翻页范围、竖排方向和音效清理列；`tests/test_font_coverage.py`对不同墨迹高度检查共用字号与基线；`tests/test_image_text_build.py`检查正立竖排、外部像素保护及组合拒绝。完整原生缓冲/裁剪/回退/恢复夹具继续运行。

构建仍使用`build_image_text.py`和`build_font_coverage.py`的现有锁定输入；新灰度头必须重编译自有profile，不能只修改预览。完整包维持813资源，标记独立候选事务升级；原安装、存档、人物名、免CD EXE、launcher、图形适配、Logo及名单均保持原字节。全部目标读回与独立回滚验证，不启动游戏。
