## LOAD-01：图形候选下读档闪退

- 报告日期：2026-10-12。反馈：载入存档后直接闪退；候选为 DDrawCompat v0.7.1 standard。
- 已验证：对应隔离会话自然退出码 `3221226525`（`0xc000041d`）；Windows Application 事件 1000 记录系统 ddraw.dll 版本 `10.0.26100.8115`、偏移 `0x0003b717`，不是本地兼容层 DLL 的版本。不能仅按模块名判定根因。
- 对应日志实际使用 T&L HAL 与 D16。HAL-only 是调查变量，不是已确认修复；独立探针仍发现退出异常，未作为默认配置。
- 已处理：保留日志及两个存档副本，撤回图形候选。未修改游戏资源、存档内容或原安装。
- 对照结果：撤回后已收到成功进入游戏、读取存档的反馈；该结果支持先撤回失败候选，不证明存档全流程或图形修复通过。
- 状态：DDrawCompat 候选验收失败并保持撤回。缺少崩溃调用栈，故障模块位置不等于根因定位。
- 后续真实转储已恢复更早异常：d3dim700.dll RVA `0x9984` 读取 `0x78`，来自驱动 SetTexture 调用。最终 ddraw.dll 异常属于后续对话框路径；完整对象状态仍未捕获，详见 [转储分析](CRASH_ANALYSIS.md)。
- 后续完整现场已取得：PID 11760 首次读取 `0xC` 的异常发生在替换旧绑定内部引用时。已实现默认关闭的删除前解绑候选，实际游戏修复仍待验收，详见 [纹理生命周期候选](TEXTURE_LIFETIME_CANDIDATE.md)。
