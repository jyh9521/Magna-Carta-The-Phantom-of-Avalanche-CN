## REA首轮输入调查结论

原MCAlpha哈希与函数边界见[MODERN_INPUT.md](MODERN_INPUT.md)。不是仅凭API名字假定DirectInput设备丢失：当前定位到GetKeyboardState/GetAsyncKeyState和GetCursorPos。窗口过程只在WM_MOUSEMOVE分支隐藏系统指针；是否因兼容层呈现窗口、消息目标、前台线程或坐标域导致双指针，需要实际故障采样。隐藏指针不能替代点击恢复。

缺陷修复按：绑定版本/存档和配置 → 得到能复现该现象的输入/现场 → REA追踪调用与状态 → 最小单变量候选 → 同输入原版/候选/回滚 → 实际游戏验收。保存商业原件，只发布源码/增量与必要技术事实。

## 高级增强门槛

先处理稳定性和输入边界；高分辨率、宽屏与60FPS分开验证。高分辨率需记录内部渲染/呈现/UI三者；宽屏需验证摄像机/视野而非拉伸；帧率需比较实际时间、移动距离、动画/事件/音画。当前没有新增60FPS、真宽屏或4K二进制补丁，也没有配置GUI占位。
