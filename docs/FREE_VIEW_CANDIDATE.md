# 渲染层环绕视角候选

## 已验证

独立 `MC_FREE_VIEW=1` 开关接入已锁定的相机LoadMatrix/Multiply路径，仅传递局部矩阵副本，不写activeCamera+80、角色、碰撞或存档。复用完整动作相机恢复链；原驱动槽、源码版本守卫与退出恢复不变。

纯数学样本19项；真实自建驱动槽接入后完整动作样本57项，包括开启视角、原相机不变、F7复位和OFF恢复原完整动作相机。失焦、相机身份变化、计时世代变化重置候选。UI投影和其他矩阵不进入候选。

候选固定组合4K宽屏/完整动作60Hz；读取原手柄设置，另写独立临时配置，不改变配置工具保存值。纹理生命周期候选在该入口关闭，避免未验收的两个候选叠加。正常旧入口不升级模块。

## 玩家验收与未验证项

这是环绕型视角，不是全自由飞行。基于原相机沿观察轴400单位的研究枢轴；该点未验证为角色中心。原相机的场景剔除、近裁剪及遮挡没有替换，转动后可能出现缺失模型；发现异常用F7或关闭入口对照。不能把样本矩阵通过称为自由视角游戏验收通过。

只在探索场景测试：进入后先松开按键，F6开关，F7关闭并复位；NumLock开启，按住Ctrl+Alt，再用小键盘4/6环绕、8/2俯仰、加/减调整距离。转动限制120度、俯仰70度、距离16至4096单位。现有游戏键盘状态不被候选吞掉；这些组合是否与具体键位配置冲突仍待玩家验证，候选默认不发布为正式操作。

验收顺序：OFF入口保持原镜头；候选入口开启、转动、距离调整、F7恢复；检查人物/地形/罗盘/菜单；打开菜单、读档和切场景检查原镜头恢复；战斗和剧情暂不列为通过项。日志、原截图和配置按session留存。未自动启动游戏。

生成：`python tools/prepare_free_view_trial.py --workspace build/configurable-modern-game --native build/advanced-display-native/Release --output build/free-view-runtime`。Play-free-view.cmd开启候选环境，实际视角初始仍关闭；Play-without-free-view.cmd显式关闭环境开关，同画质对照。
