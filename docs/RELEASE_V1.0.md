# v1.0 · 《真名法典：冰之魅影》简体中文汉化 + 全面增强补丁

**Magna Carta: The Phantom of Avalanche Simplified Chinese Localization & Enhancement Patch**

面向初代 PC 版《真名法典：冰之魅影》的简体中文汉化与全面增强补丁。v1.0 将汉化、高清显示、流畅度改进、地图、战斗辅助和运行修正整合为一个覆盖包，安装时无需串联历次测试补丁。

**[项目原始发布页 · 伯翎飞云](https://blog.blfy.cc/posts/magna-carta-the-phantom-of-avalanche-cn/)**

## 这次做了什么

### 简体中文汉化

- **剧情与资料文本**：覆盖主线、支线、教程，以及人物、地点、物品、技能等结构化文本；目录共 4,137 个字段，其中 4,091 条译文、46 条明确保留记录。
- **界面与系统提示**：汉化菜单、存取档、装备、战斗反馈、系统消息等文字与图片，并处理中文编码、字库、字形覆盖、测量和排版。
- **标题与视频文字**：制作中文标题画面，处理开场、Game Over 等视频文字，保留原有配音与音轨。
- **版本标识**：标题右下角显示 `Original: v1.04a` 与 `CN Localization & Enhancement Patch: v1.0.0`，沿用原生字体和描边，不增加背景底板。
- **显示细节修整**：修正旧字残影、跨图片拼接、长句显示、字幕重叠与收尾等问题；高分辨率下使用配套高清字形。

### 画面与流畅度增强

- **高分辨率与宽屏**：提供 1080P、2K、4K、自适应分辨率和 16:9 宽屏显示。
- **窗口模式**：支持全屏、窗口化、无边框窗口化；窗口化可单独选择窗口尺寸。
- **30 / 60 帧切换**：60 帧模式加入人物、怪物通用模型及镜头插值，保留原有游戏逻辑速度，而不是把游戏整体加速。
- **免光盘启动**：整合匹配版本的启动修正，安装后直接从游戏目录启动。
- **现代 Windows 兼容**：整合图形与运行兼容组件，处理窗口切换、启动、载入和相关显示问题。

### 地图与操作辅助

- **区域地图**：按 **F9** 在小地图、全屏半透明地图、关闭之间切换；覆盖 174 个区域，便于查看区域结构。
- **随机遇敌开关**：按 **F5** 切换随机遇敌，不影响剧情战斗、强制战斗及已经开始的战斗。
- **普通连招辅助**：按 **F10** 使用普通连招辅助。
- **暴走连招辅助**：按 **F11** 使用暴走模式连招辅助。

### 运行与体验修正

- 整合对白揭示、长对白收尾、剧情字幕与场景载入相关修正。
- 修正战斗菜单宽度、伤害数字投影和技能镜头中的数字显示。
- 纳入模型动作连续性、镜头切换及插值路径的改进。
- 整合探索碰撞处理、局部脱离及连招声音后端改进，并保留排错用的对照启动方式。
- 补齐匹配版本的运行依赖与旧安装兼容资源，减少因基础库缺失或版本混用导致的启动失败。

### 安装与配置

- **Configure.exe**：图形化设置、恢复默认、检查入口和启动游戏。
- **Game.exe**：直接启动，另提供文件检查与原版资源恢复命令。
- 配置与启动逻辑已编译，玩家无需安装 Python 或执行 PowerShell 脚本。
- 个人设置保存在游戏目录的 `enhancements.json`；覆盖更新不重置设置、不移动存档。
- 受保护安装目录按需请求管理员授权，日志和临时缓存单独存放。

## 下载与安装

完整补丁附件：`MagnaCarta-zh-CN-v1.0-release.zip`。此包不含完整游戏，需要已有匹配版本的原版游戏。
GitHub 自动生成的 **Source code** 压缩包是工程源码，不是玩家补丁。

1. 退出游戏和配置工具，备份原版游戏与个人存档。
2. 将补丁 ZIP 的**全部内容**解压至 `MagnaCarta.exe` 所在目录，覆盖同名文件，保留子目录结构。
3. 打开 `Configure.exe`，点击“检查入口”，通过后选择设置并保存。
4. 点击“启动游戏”，或双击 `Game.exe`。

**默认：1080P / 无边框窗口化 / 60 帧。** 运行环境为 Windows 10/11、.NET Framework 4.x / WPF。
已安装旧版时，同样完整覆盖即可；无需叠加历史小补丁，也无需手动清除旧版脚本才能使用新入口。

## 使用说明

| 快捷键 | 功能 |
| --- | --- |
| F5 | 开启 / 关闭随机遇敌，每次启动默认开启 |
| F9 | 小地图 → 全屏半透明地图 → 关闭 |

地图为区域线稿参考，不是寻路导航；多层结构可能叠合，0084、0096 区域暂不显示地图。
v1.0 使用键鼠操作；手柄支持和自由视角研究未纳入发行功能。
开发人员名单、SOFTMAX Logo、部分装饰文字和旧存档名称保留原样。

此前完整补丁已收到通关反馈。后续桌面封装和地图呈现修订另有离线回归记录；完整通关反馈不代表所有硬件、场景与显示组合均已逐项验证。
碰撞、连招声音和特殊镜头表现仍欢迎提供具体场景反馈，不将“全面增强”解释为所有历史问题均已消除。

## 排错与恢复

检查失败时，先确认解压层级和覆盖完整性，再根据提示核对具体文件。请勿混用不明来源的 DLL 或重复叠加旧测试包。

在游戏目录打开终端后，可执行：

```powershell
.\Game.exe --check-installed
.\Game.exe --verify-only
.\Configure.exe --self-test
```

恢复原版资源前，准备独立、匹配版本的原版备份，并将示例路径替换为实际位置：

```powershell
.\Game.exe --check-baseline "D:\原版备份目录"
.\Game.exe --rollback "D:\原版备份目录"
```

恢复保留存档、个人设置、显示 INI 与检查工具；完成后使用原版游戏入口。
碰撞或声音问题可用 `Game.exe --without-test-candidates` 启动对照；动作或显示问题可切换 30 帧比较。

日志位于 `%LOCALAPPDATA%\MagnaCarta\Installations\<安装标识>\cache`。
反馈请附版本、场景、复现步骤、显示设置、截图与对应日志，可在[项目原始发布页](https://blog.blfy.cc/posts/magna-carta-the-phantom-of-avalanche-cn/)或 [GitHub Issues](https://github.com/jyh9521/Magna-Carta-The-Phantom-of-Avalanche-CN/issues)提交。
