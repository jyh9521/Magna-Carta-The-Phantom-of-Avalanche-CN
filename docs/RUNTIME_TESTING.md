# 运行与增强功能验收清单

已取得原版样本。首次原版启动报告错误为 `Cannot Match PixelFormat`；后续独立 Direct3D 未更新驱动副本已收到当前读档场景画面正常反馈，详见 [驱动对照验收](UNPATCHED_DRIVER_TRIAL.md)。下列清单是完整验收协议，不将有限场景反馈扩展为全项通过。

## 记录格式

### 测试启动条件

游戏实测前先通知测试内容，收到明确测试确认后才启动；默认采用手动启动。静态检查和非交互测试不启动游戏，不切换桌面显示模式，不结束既有进程。后台启动仍属于游戏实测，不作为例外。

### DISPLAY-01 模型可见性回归

状态：待复现、未修复。首次报告为模型间歇性消失与重现，不能以进入菜单或加载 Direct3D 认定显示正常。
测试确认后记录以下对照：

1. 固定副本、存档、场景、镜头、角色位置和操作顺序，保存驱动与配置 SHA-256；先保留无图形兼容层基线。
2. 连续录像覆盖模型消失前后，记录静止、移动、镜头变化及遮挡关系；区分模型整体、局部网格、贴图和背景异常。
3. 每次只改变一个经过版本核验的候选，分别比较同场景结果；未验证候选不覆盖基线、不自动应用。
4. 恢复基线后重复相同操作。记录正常显示时长、异常次数、场景范围与恢复结果；有限测试没有异常不等于全程修复。

每次测试记录：测试 ID、版本/SHA-256、资源语言、补丁与 Drv 哈希、Windows build、GPU/驱动、显示器、DPI、刷新率、兼容层版本与配置、步骤、预期、实际、日志/截图/存档路径、结果、回滚结果。
结果使用：通过 / 失败 / 未执行。韩文与中文分别执行；测试程序和模拟样本不计为游戏实测。

## 原版和无盘对照

1. 在备份副本建立原版有盘基线，记录新游戏、读档、场景与媒体。
2. 导出安装/盘文件清单与 SHA-256，保存相关配置和安装登记；仅以有依据的原生机制调整路径。
3. 确认所有游戏盘已卸载，保存光驱/卷记录；测试期间不得自动挂载。采集主进程及子进程的文件访问、模块加载与报错。
4. 从启动到退出覆盖下表；检查失败的盘路径访问，也检查是否退化为无音乐、缺视频或场景资源缺失。
5. 恢复原始配置和文件，重复相同输入，验证基线恢复。每个版本和模块组合单独记录。

| ID | 验收内容 | 预期 |
|---|---|---|
| CD-01 | 无实体盘、无 MC_PLAY 挂载启动 | 从硬盘进入菜单，无隐藏挂载 |
| CD-02 | 新游戏、已有存档、存档后读取 | 进度和文本正常，无数据损坏 |
| CD-03 | 多剧情阶段、多场景往返 | 资源完整，事件正常；不是只测开场 |
| CD-04 | BGM、音效、语音和过场动画 | 各资源实际播放，比例和同步正常 |
| CD-05 | 退出后重新启动与读档 | 不依赖前次进程或盘缓存 |
| CD-06 | 最小中文资源及后续正式中文资源 | 字体、控制符、文本和资源加载正常 |
| CD-07 | 官方更新和已验证兼容修复 | 分版本复测，光盘访问无回归 |

最终全程支持还须覆盖主要剧情/场景和媒体目录。有限场景冒烟通过只报告所测范围。

## 窗口与显示（P1 优先）

- 先记录无兼容层的图形模块、渲染/输出尺寸和原始比例。确认 API 后一次添加一个候选，保存 DLL、配置与原件哈希。
- DDrawCompat 条件试验：只在确认 DirectX 1–7 路径后使用官方版本，在游戏副本设置 `FullscreenMode=borderless`；验证日志显示实际加载。设置存在不等于游戏支持。
- 测试普通窗口、独占全屏、无边框；Alt+Tab 至少 20 次，Alt+Enter（若支持）至少 10 次；失焦恢复、最小化、关闭和重启。
- 主副显示器分别测试居中、负坐标位置及不同 DPI；100%、125%、150%、200% DPI；60/120/144Hz 在硬件允许范围内记录。
- 先测 1920×1080，再覆盖路线图全部分辨率与 16:9/16:10/21:9。逐项核实 UI 边界、中文清晰度、点击点、2D 背景、3D 模型、视频比例和性能。
- 同场景截图记录内部渲染、输出和 UI 尺寸；真实宽屏需证明视野扩展且不裁切/拉伸。缩放输出不得报告为原生高分辨率。
- 检查非韩文区域设置、路径字符、普通权限存档写入与 VirtualStore；不默认要求长期管理员运行或修改系统区域。

## 输入、帧率及模块回归

- 各手柄型号和有线/无线方式分别记录；全动作映射、标签布局、自定义键、死区、断开/重连、设备切换与键鼠同时输入。
- 键盘事件模拟只验收为模拟支持。不存在的动作不添加虚假选项。
- 同场景比较原始计时、30/60 FPS 候选下固定时间移动距离、动画/事件时长、战斗输入和音画同步；记录帧时间和异常。
- 确认高性能 CPU、高刷新率、长时间游戏不改变速度；时序绑定未解决时维持原始稳定模式。
- 增强模块逐个关闭及恢复；GUI 仅验收已实现设置，核实失败恢复、默认值、独立游戏启动和开销。

离屏测试不启动游戏、不切换桌面模式，不替代完整场景遮挡和玩家画面验收。

## 退出门槛

保存实际结果后才更新支持范围。任何资源丢失、存档风险、进度阻断、鼠标错位或时序异常均阻止对应模块发布。
第三方版本及许可未核实不打包；保护机制修改另行记录授权条件；不以挂载隐藏化代替无盘验收。
