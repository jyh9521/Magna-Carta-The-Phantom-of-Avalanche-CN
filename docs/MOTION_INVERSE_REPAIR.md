# 60FPS候选：近刚体相机逆变换

## Verified：实现缺陷与受控钩子复现

`motion::rigid()` 接受带轻微伸缩/剪切的矩阵，但原 `inverseRigid()`
只转置左上3×3。当矩阵并非严格正交时，转置不等于逆矩阵。
其调用点包括相机视图/位姿转换、从modelview提取actorWorld以及环绕视角。

数学回归采用原容差已接受的1.008缩放、0.005剪切、90度旋转和三轴平移，
验证左右乘积、两次逆变换以及相机首帧。旧生产代码实际输出：
`FAIL near-rigid inverse cancels native stretch and shear on both sides`。

实际相机驱动槽与人物render/absoluteHook的非商业回放使用静止人物x=12、
原生视图平移-20和缩放1.008。原native modelview位置为-7.904；
旧逆变换链在首帧即改变该位置，输出：
`FAIL real camera hook near-rigid first frame preserves native modelview`。
这不是玩家游戏截图，亦未执行商业代码。

## 修正与验证

保留原API名称及近刚体准入范围，用3×3余子式/行列式计算实际逆变换，
使用双精度计算行列式和平移，结果仍为float矩阵。非有限数/不受支持的
矩阵直接保持输入，不拓宽大缩放、反射或透视矩阵支持。
该函数针对原有仿射近刚体路径，不宣称通用4×4逆矩阵。

152项数学检查、86项真实钩子检查及19项环绕视角核心检查通过。
独立源回滚恢复103/82项原行为；主动模块保持修正。
逻辑33ms时钟、骨骼动作帧、输入映射、事件及汉化资源未改。
原相机在钩子退出后逐字节恢复；人物modelview恢复检查通过。
