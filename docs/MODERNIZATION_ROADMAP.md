# 现代 Windows 与无盘运行技术路线

更新：2026-10-12。目标平台：Windows 10 / Windows 11（64 位）。
本文记录正式开发目标，不代表功能已实现。静态依据见 [运行环境调查](RUNTIME_RESEARCH.md)，验收见 [测试清单](RUNTIME_TESTING.md)。

## 当前状态与开发门槛

- 已验证：初步调查时本地是工程规范模板目录，没有 `.git` 元数据；随后接入正式远端，并于 2026-10-12 重建为独立历史。新增文档测试不代表游戏工具链已建立。
- 原版安装目录、启动 EXE、运行盘样本和官方更新文件尚未提供；游戏架构、图形 API 版本、编码、原始分辨率和帧率均待确认。
- 无盘运行、无边框窗口、中文显示、原生高分辨率及现代手柄均为待实测目标。
- 汉化与兼容性可以并行调查，但共享同一版本锁定、原始基线和回归门槛。大规模翻译前须完成最小中文运行证明和首次跨作品术语核实。

## 无盘运行

目标是安装后直接从硬盘游玩，不依赖实体 CD 或 MC_PLAY 镜像；禁止隐藏式自动挂载。

1. 对比安装目录与 MC_PLAY 文件清单、大小和 SHA-256，确认音乐、语音、视频或场景资源是否仅在盘上。
2. 区分介质存在性、卷标、资源路径、版本、安装登记及其他启动条件；报错文本不等于根因。
3. 分别调查原版、官方更新、英文汉化；保留各版本 EXE、Drv、配置及资源哈希。
4. 优先调查完整硬盘安装、原生路径设置和路径兼容修复。只有存在可验证依据时才实施配置或兼容启动器。
5. 若涉及复制保护，先记录机制、授权条件和风险，暂停该修改路径；本阶段不实施保护绕过。
6. 当前实现方案未选定。安装与使用方法待验证后填写，不能把候选配置当成玩家安装指引。

## 显示与窗口

- 先识别实际加载的图形模块及 API，不根据 DLL 文件名断言 DirectX 版本。
- 每次仅测试一个兼容层；原版、补丁后 Drv 和恢复原版 Drv 各自建立独立基线，不叠加代理 DLL 或钩子。
- 分开记录：原生渲染提升、低分辨率缩放输出、UI/字体独立缩放。优先原生提升，缺乏证据时保留比例缩放。
- 分辨率目标：1280×720、1366×768、1600×900、1920×1080、2560×1440、3840×2160。
- 比例目标：16:9，进一步研究 16:10、21:9。真实宽屏须验证视野和摄像机；保留原比例优于横向拉伸。原始比例待测。
- 无边框优先；同时评估普通窗口与独占全屏、Alt+Enter、Alt+Tab、居中、多显示器、失焦恢复、DPI 和鼠标坐标。尽量不改变桌面显示模式。
- dgVoodoo2、DDrawCompat、cnc-ddraw、DxWnd 都是候选，不代表本作兼容；选择和许可证依据见调查文档。

## 输入与计时

- 先核实原有键盘、鼠标及手柄输入机制。Xbox、DualSense、DualShock 4、Switch Pro 和其他 XInput/SDL Gamepad 设备分别验收。
- SDL3 Gamepad / XInput 为候选。键盘映射若采用，明确标记“模拟手柄支持”。
- 默认建议：左摇杆/十字键移动，A/×确认，B/○取消，Start/Options 菜单；LB/RB、LT/RT 必须按实际动作定义。
- 提供自定义映射、Xbox/PlayStation/Nintendo 标签布局、摇杆死区、键鼠共存、连接断开和运行中切换处理。
- 核实动画、逻辑、输入和音频时钟。研究 30 FPS / 60 FPS，而非强行解锁；帧率上升不得改变移动、战斗、剧情和音画同步。

## 模块和配置工具

分离汉化资源、字体/文本渲染、图形兼容、输入适配、启动/配置、自动化测试。
各增强模块独立启用、禁用和回滚，关闭后须恢复原版基线。

核心功能验收后再开发 **Magna Carta Configuration**：分辨率、模式、比例、帧率、兼容层、手柄映射、语言、启动和恢复默认值。
只显示真实有效且经过验证的设置；无复杂运行时和强制冗余组件；游戏保留独立启动方式；配置失败可恢复；测量额外性能开销。
本阶段不制作占位 GUI，也不分发未经评估的第三方二进制。

## 下一阶段可执行任务

1. 用户安装韩文原版后，在副本上收集版本、文件哈希、注册表/配置和依赖，不修改唯一原件。
2. 建立原版启动、存读档、媒体和场景基线，采集实际文件访问及模块加载记录。
3. 对照 MC_PLAY 清单和无盘访问记录，优先验证原生硬盘资源路径。
4. 确认 API 后选择一个兼容层验证无边框与 1080p 输出，完成 P1 测试后再扩展。
5. 以同场景截图、保存文件和时序记录将结果归档，再推进输入、高分辨率及 GUI。

## 发布规则

公布实际验证的版本哈希与组合；未测组合标记未测。保存安装、卸载、配置恢复说明与第三方版本/许可。
保留原版与修改版对照、错误复现及回滚证据，增量补丁不得包含完整商业游戏资源。
