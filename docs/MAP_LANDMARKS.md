# 区域地图：对象层和玩家跟随

## Verified：旧图缺少对象层

现有地形图只投影WRD几何，0009等资源显示大块平面；没有原NPC／箱体的位置层。
原6f9a3从scene+1594列表头（+159c）遍历，节点+0为对象、+4为next，
对象+f0为场景资源标识。原5dbb0读取对象+48/+4c/+50坐标，
原邻近判断用这些值与玩家坐标求距离。原4ca82检查对象+d4，非零对象跳过。
原对象ID16a是FNPC，168是FBOXOBJ。支持的MCAlpha源SHA与原地图观察器相同。

新观察器在原世界tick之后只读这些值，不调用NPC行为或修改剧情状态。
每帧最多遍历256节点、记录64个地标，防循环和非有限坐标；不完整遍历在计数后显示`+`。
蓝圆表示NPC，紫方表示箱体；箱体不代表仍有未领取道具，不推断任务或出口。

## 地图表现

橙箭头显示玩家位置和原方向向量；黄色线显示本次游玩的最近移动轨迹，
最多128点。移动不足4世界单位不重复记录；换地图/玩家对象或超过200单位跳变时清空。
轨迹只在内存中存在，未写存档，也不表示已验证可通行路线。
小地图以玩家为中心，显示约240世界单位范围（受到图像采样范围限制）。
大图保持整区域参考；添加坐标格、当前位置及对象计数。
坐标后`!`表示玩家超出地形预览范围，不能把边缘夹住的点当作真实位置。

图例来自locale数据生成的UTF16资产，generic模块不硬编码中文。
原地图图像、原中文翻译、字体、模型和存档未改。

## 玩家验收

键盘入口`runtime/Play-maps.cmd`：F8大图，F9小图，再按关闭。
手柄入口`runtime/Play-maps-gamepad.cmd`：View/Back大图，R3小图；先松开按键再操作。
所有入口共享`runtime/data`，未复制游戏。

1. 在有NPC的区域打开图，比较蓝圆和人物相对位置；箱体附近检查紫方。
2. 行走和转身，橙箭头应跟随，轨迹增长；小图玩家应保持在中间。
3. 开菜单、换地图、读取存档，检查旧对象和轨迹不会误留在其他区域。
4. 检查坐标后是否出现`!`，以及地图仍空白或资源缺失的区域ID。
5. 地图仍是穿透图层，不暂停游戏，不抢前台；不作为Alt+Tab修复。
